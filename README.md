# eSpeleoSociety 2

Informačný systém Slovenskej speleologickej spoločnosti (SSS): evidencia skupín a členov, elektronický
jaskyniarsky preukaz (eCP) v Google Wallet, PDF kartička SSS, členské poplatky a portál pre členov,
predsedov skupín a administrátorov.

Projekt je vo fáze 0 (základ). Nahrádza pôvodný projekt
[speleo-dev/eSpeleoSociety](https://github.com/speleo-dev/eSpeleoSociety).
